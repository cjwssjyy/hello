# 班级课程查询

网站地址：https://cjwssjyy.github.io/hello/

手机优先的班级共享课表，提供今日课程、下一节课、明日预览、本周课表和已提前确认的课程调整。

本页不是官方教务系统，也不是紧急通知工具。当天临时变动、临时换教室等，以班群及教师通知为准。

## 维护课程

页面仅提供本周及以后周次；按北京时间每周一自动移除已结束周的选项，上一周按钮也不能进入历史周。跨周时仍打开着的页面会在定时刷新或回到前台时更新。过往周的调整通知同步退出列表，仍影响未来日期的跨周调课继续保留。学期结束后显示“未发布”，不沿用旧学期课程。

2026年10月20日已清理第8周以前的课程周次和仅历史周使用的课程，当前源数据范围为第8—18周。自动退出列表属于页面显示规则，静态网页不会自行写回 GitHub；后续维护时再清理源数据中结束的周。清理前保留本地副本，并核对未来日期的排课结果一致，尤其不能删掉未来调课引用的原课程。

换学期时直接替换 `schedule.js` 的当前学期数据：更新 `term.weekOneMonday`、发布周范围、`courses`、`changes`、`studyExceptions`、自习规则和 `updatedAt`，同时修改 `index.html` 中的学年学期标题。新学期周次重新从1计算；不要把新学期课程追加到旧数组。旧学期如需留档只保存在本地或 Git 历史中，不作为网页查询入口。

- `schedule.js` 是唯一课程数据源；课程内容发生变更时更新其中的 `updatedAt`，使用北京时间和 `+08:00` 时区。
- `weekday`：周一为 1，周日为 7；`weeks` 指实际开课的教学周。第 7 周为 2026 年 10 月 12 日至 18 日。
- 课程时间使用 `start`、`end`，页面显示时间，不显示节次。单次调整使用现有 `changes` 结构，沿用原有字段。
- 保留已经确认的英语分班、日语生标注、每天早自习，以及日语晚课不影响其他同学晚自习的规则。
- 无法确定的日期、时间、教室或冲突先核实，不推测课程安排。

当前入口不再引用旧的 `motion.js`；请勿重新接入旧动效。

2026年10月21日的动效是在原日历弹入、连续摇摆和轻量切周上增加纸飞机、路径及印章，恢复扩散光圈和彩纸。手机上背景光晕保持静态，整块扫光仅开场一次；动效循环仅改变 transform / opacity，后台及顶部离屏时暂停，并遵循减少动态效果设置。本版已做源码和资源一致性检查；当前测试环境图形进程启动失败，尚未完成该版手机模拟及真实手机帧率检查。

## 发布检查

1. 先拉取 `main` 的最新提交，再核对当前网站与待修改内容。
2. 修改后校验完整课程数据，检查受影响日期、今日/明日和本周课表；界面变更额外检查手机布局与动效。
3. 修改 CSS 或 JS 后同步更新 `index.html` 中对应资源的缓存版本。仅调整视觉或维护文档时，不修改课程的更新时间。
4. 查看差异，只提交网站相关文件，正常推送到 `main`；不强制覆盖仓库历史。
5. 推送后核对 GitHub Pages 部署与线上资源。上传成功和网站已发布应分别确认。

登录凭据、SSH 私钥、原始截图、原始 Excel 与本地测试文件不应上传至此仓库。


纸飞机后续可见性修正：装饰移入日历容器，使用 z-index:6 位于纸面前方；沿日历外缘做连续360度圆周飞行，虚线路径半径与飞行一致，手机尺寸分别缩放至0.72/0.62。保持 pointer-events:none、离屏/后台暂停与减少动态效果设置。
